PARA OS RESPONSÁVEIS

Aprender no próprio ritmo

Ande com as setas da tela (ou do teclado). Perto de uma bandeira, toque em Explorar. Há nove pontos de atividade e nove trilhas de aprendizagem. Cada trilha tem três etapas, com três atividades por etapa. O caderno permite abrir as atividades diretamente. Procure também os animais pelo caminho!

Há um progresso por explorador neste navegador. Limpar os dados do navegador apaga esse progresso. As etapas registram atividades concluídas. Repita com a criança sempre que necessário. A voz depende das vozes instaladas no aparelho.

Preparando o modo offline…

Para usar a versão independente gratuitamente no GitHub Pages, baixe o pacote e envie os arquivos extraídos do pacote ao repositório. Ative Pages em Settings → Pages → main / root.
